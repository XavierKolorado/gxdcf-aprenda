# GXDCF Aprenda

Plataforma estática de aprendizagem de programação em português, feita com HTML, CSS e JavaScript puro.

## Como executar

Abra `index.html` no navegador ou sirva a pasta com qualquer servidor estático local. Não há dependências, backend, login ou configuração de banco de dados.

## Trilhas disponíveis

- Lógica de programação com pseudocódigo didático inspirado em Portugol (opcional, 10 módulos).
- Python, com uma trilha inicial de 10 módulos.
- JavaScript, Java e C#, com conteúdo introdutório identificado como tal.

As aulas ficam no ambiente único `curso.html`; use parâmetros como `curso.html?linguagem=python&aula=variaveis` ou `curso.html?linguagem=portugol` para abrir uma trilha. Os identificadores antigos de trilha e aula continuam aceitos.

## Progresso e exercícios

As aulas concluídas, a trilha e aula recentes, respostas corretas e progresso por trilha são armazenados no `localStorage` deste navegador. O conteúdo pode ser acessado sem cadastro. Os exercícios validam respostas no navegador; o código digitado pelo aluno não é executado.
